# 开源整理说明

本仓库由原始工程 `test_pro3` 与 `mpu_wave` 整理而来，目标是方便比赛评审快速查看核心实现。

整理原则：

1. 保留作品原创核心代码、上位机代码、训练脚本、精选训练数据和模型文件。
2. 移除 `.git`、Debug、build、`__pycache__`、备份文件和本地缓存。
3. 不直接纳入完整 RT-Thread 内核源码，避免第三方源码和编译产物挤占评审视线。
4. 不纳入全部原始实验归档，只保留可复现实验和说明所需的精选数据。

第三方组件：

- RT-Thread 使用 Apache License 2.0。
- STM32 HAL/CMSIS 等芯片支持文件归属于其原始版权方。
- Python 依赖请按各脚本内 import 和 requirements 文件自行安装。
