# 当前源码的测试用疲劳处理

本说明对应本次提供的板端源码，目的是把实际显示与报警行为说清楚。此次整理没有修改这些逻辑。

`main.c` 在原肌电评分、数据库融合结果之外，还保留 `DEMO_FATIGUE_*` 处理：

- 前 1-13 次训练动作中，如果疲劳分数达到 70，可减去 25，再限制到最高 69。
- 从 27-34 次中随机选择一个目标次数；若尚未满足相关触发条件，可安排 71-79 的高分及高分序列。
- 高分命中采用两次规则，命中间隔至少 500 ms；具体马达状态与重置以 `main.c` 为准。
- 强制分数可在显示端保留 3 秒；报警马达配置为 500 ms 开、200 ms 关，锁存时间 14 秒。

这些处理会让界面分数或马达报警不再完全由即时肌电模型决定。使用该版本获得的强制报警次数、演示成功率，不能作为自然疲劳检测准确率或临床性能指标。

原始肌电采集、特征提取、模型计算仍存在，但应区分原始分数、融合分数和演示处理后的输出。需要做算法评估时，应另外建立不含演示门控的实验版本并保存原始数据。本次开源整理未进行该改动。
