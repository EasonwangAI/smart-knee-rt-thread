# 蓝牙整合高速显示、完整写盘与疲劳峰值保持版

本工程基于 `Blue.zip` 中的蓝牙/ESP32 热点整合版本建立，保留原有
ADS1292R 肌电采集、MPU6050 姿态检测、动作计数、随机森林疲劳识别、
数据库匹配、圆屏显示、马达报警和 ESP32 网页显示功能。

## 本版本修改

- 圆形 TFT 刷新周期恢复为 80 ms，约 12.5 Hz。
- 数据库实时 CSV 写盘恢复为每次 LIVE 调用都记录，约 20 Hz。
- 圆屏显示最近 1000 ms 内的最高疲劳值，避免短暂峰值立即消失。
- 串口、数据库、ESP32 输出、疲劳报警和马达仍使用实时疲劳值。
- 保留 GC9A01 SPI 发送检查、初始化重试和异常自动重绘。
- 保留 ESP32 数据格式：`KNEE,score,action,count,alert`。
- 动作计数、姿态阈值、MPU6050 20 ms 采样周期、随机森林模型和
  70 分疲劳报警阈值均未修改。

## 疲劳值为 0 的排查

疲劳分数在以下阶段按设计为 0：

1. 上电后的静息校准尚未结束，约需 10 秒，期间应保持腿部放松。
2. 主动收缩校准尚未收满 40 个有效窗口，需持续明显发力约 5 秒以上。
3. 进入运行阶段后，随机森林尚未累计 24 个连续有效窗口，约需 3 秒。
4. ADS1292R 的 CH2 信号低于活动阈值，模型窗口会被清空。

串口可查看 `CAL`、`LIVE` 和 `emg_status_dump` 信息，确认当前处于
`REST_CAL`、`ACTIVE_CAL` 还是 `RUNNING`。仅恢复屏幕和写盘频率不会改变
疲劳算法本身。
