# 启动校准门控版本说明

本工程基于 `test_pro3_blue_fast_io_fatigue_hold_v2` 创建，不覆盖原工程。

## 上电流程

1. 上电后保持站立、腿部静止并放松目标肌肉。
2. 静息肌电校准期间，动作计数与姿态检测保持锁定，圆屏显示 `REST CAL`。
3. 静息校准结束后，马达短震约 300 ms。此时继续保持直立并主动绷紧大腿，圆屏显示 `ACT CAL`。
4. 主动肌电校准结束后，马达长震约 800 ms。此时进入正常运行，动作计数、姿态检测、疲劳识别、数据库匹配、屏幕、串口和 ESP32 输出全部启用。

## 保持不变的部分

- MPU6050 读取周期仍为 20 ms。
- 动作开始、返回、重复计数保护和最短动作时间阈值未修改。
- 深蹲与硬拉的 24 度分类线未修改。
- 姿态评分算法未修改。
- ADS1292R 采样、肌电静息/主动校准、随机森林和数据库匹配算法未修改。
- TFT 仍为 80 ms 刷新，并显示最近 1000 ms 内的疲劳最大值。
- 串口、数据库、ESP32 和疲劳报警仍使用实时疲劳值。

## 震动含义

- 短震一次（约 300 ms）：静息校准完成，开始主动收缩校准。
- 长震一次（约 800 ms）：主动校准完成，进入正常运行。
- 正常运行后的周期性震动：原有疲劳报警。
