# 双 MPU6050 独立姿态测试模式

本版本暂时不使用压力传感器判断膝盖内扣或向外扩，姿态结论只来自大腿和小腿两颗 MPU6050 的相对角度。

当前校准后的相对角采用带符号定义：`+5°`及以上判定为膝盖内扣，`-40°`及以下判定为膝盖外扩/外翻，中间范围保持正常。阈值常量内部使用 0.1° 整数单位，分别为 50 和 400。

## 当前阈值

- 膝盖向内扣方向：+5.0°，连续满足 8 个采样（160 ms）触发。
- 膝盖向外扩方向：-40.0°，连续满足 8 个采样（160 ms）才触发。
- 一次动作中内扣优先锁存，站起时的反向瞬态不能覆盖内扣结果。
- 动作结束后结果保持 1 秒。

当前向外扩/外翻触发阈值为-40°。

## 压力传感器处理

- PC0/PC1压力ADC仍可采样和输出原始值，方便以后恢复或对比。
- 压力差不再参与内扣/外扩状态。
- 压力翻转特征暂时不参与走路、深蹲或硬拉的动作分类。
- 原有 `PRESS` 数据格式不变，但其中 `status` 由双IMU姿态映射得到，旧ESP32/App无需修改。

映射关系：

```text
KIMU VAL（内扣）      -> PRESS status=LAT
KIMU OUT（过度向外）  -> PRESS status=MED
KIMU NEU（正常）      -> PRESS status=BAL
KIMU CAL              -> PRESS status=CAL
KIMU ERR/OFF          -> PRESS status=ERR
```

该映射对应App继续选择“内侧偏高 = 外翻/向外扩”的现有设置。

## 测试步骤

1. 按 `DUAL_IMU_SEPARATE_BUS_WIRING_CN.md` 接好两颗MPU6050。
2. 压力传感器可以不佩戴；PC0/PC1悬空不会参与姿态或动作分类。
3. 站直静止后上电，等待 `KIMU,CAL_DONE`。
4. 正常深蹲时应主要显示 `KIMU ... status=NEU`。
5. 故意轻微内扣并保持至少160 ms，应显示 `status=VAL`。
6. 如果故意内扣显示 `OUT`，执行一次 `knee_imu_flip` 后重试。
7. 使用 `knee_imu_info` 查看当前相对角度、峰值和方向符号。

注意：所谓“只依靠新增MPU”在算法上实际是用原大腿MPU与新增小腿MPU共同计算相对角度。单独一颗小腿MPU无法区分整条腿倾斜和真实膝关节相对偏转。
