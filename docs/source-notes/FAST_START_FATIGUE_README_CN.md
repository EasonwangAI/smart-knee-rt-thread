# 快速启动与跨动作疲劳识别版本

本工程基于 `test_pro3_blue_fast_io_fatigue_hold_startup_cal_v3` 单独创建，原 V3 工程没有被覆盖。

## 上电使用流程

1. 戴好护膝，上电后保持站直，并放松被测腿部肌肉。
2. MPU6050 使用 50 组数据建立角度零点，约需 1 秒。
3. ADS1292R 使用 20 个重叠窗口建立静息肌电基线，整个启动等待约 3 秒。
4. 静息校准结束后，马达短震约 300 ms，表示动作计数、姿态检测、疲劳识别、屏幕和无线输出均已启动。
5. 用户可直接开始运动。主动肌电基线会在前 20 个有效活动窗口中后台学习，不会暂停动作计数。

## 疲劳识别调整

- 保留原随机森林模型：150 棵树、12 个肌电特征、24 个有效活动窗口；模型文件没有修改。
- 每次深蹲之间的短暂停顿不再立即清空疲劳窗口，连续静止约 2 秒后才开始新一轮累计。
- 约 1 秒一次的深蹲也能跨动作累计有效窗口；通常累计约 3 次有效动作后，随机森林才拥有完整的 24 帧输入。
- 疲劳分数取随机森林结果与个人基线变化趋势中的较高值，再使用“快速上升、缓慢下降”的平滑方式，减少疲劳值长时间为 0 或瞬间消失的问题。
- 疲劳显示与震动报警阈值统一为 55。
- 活动判定最低阈值为 2000，并按静息 MAV 的 2 倍自适应，降低有效肌电被误判为静息的概率。

## 明确保留不变的内容

- 动作计数状态机及其全部角度、速度和时间条件。
- 深蹲与硬拉的 24 度分类分界线。
- 姿态评分算法。
- MPU6050 的 20 ms 读取周期。
- ADS1292R 的 500 Hz 采样链路。
- TFT 的 80 ms 刷新周期和最近 1 秒疲劳最大值显示逻辑。
- 数据库实时记录、Top-K 匹配和 ESP32 输出格式。

## 演示注意

上电最初约 3 秒必须站直、静止并放松肌肉。马达短震后再开始深蹲。首次疲劳结果需要累计足够的有效活动窗口，不应把刚开始的 1 至 2 次动作显示为 0 直接理解为传感器失效。
