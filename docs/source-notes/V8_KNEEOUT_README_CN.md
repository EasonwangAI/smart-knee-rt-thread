# V8 数据库与 ESP32 输出解耦版

本工程从最终 V6 复制，保留原动作计数、姿态分类、疲劳评分、马达、TFT 和数据库逻辑。

本版只调整并发结构：

1. 数据库线程完成 Top-K 匹配后发布一份完整缓存；TFT、疲劳融合和无线输出读取缓存时不等待数据库扫描锁。
2. `KNEE,score,action,count,alert` 从原 `fitprint` 线程迁移到独立 `kneeout` 线程，每 500 ms 输出一次。
3. 数据库 CSV 写盘仍保留原互斥锁，不降低记录频率，也不采用拿不到锁就丢弃数据的做法。

保持不变的关键参数：

- ADS1292R：500 Hz
- MPU6050：20 ms
- TFT：80 ms
- KNEE 输出：500 ms
- 深蹲/硬拉分界：24 度
- 动作计数状态机和疲劳报警规则：与 V6 相同

正常串口输出示例：

```text
KNEE,65,SQUAT,12,1
```

ESP32 只需要解析以 `KNEE,` 开头的完整行，其他调试日志可以忽略。
